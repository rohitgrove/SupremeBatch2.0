Given an input text or string. Each word in the text contains a digit (1 to 9) . 
From each word replace the character at the specified digit position in that word with the character 'M'. and also remove 
digit.

Example:

Given input string
str = "welcom3e t1o compu2ter wor1ld"

Output : "weMcome Mo cMmputer Morld"

Explanation:

The word `welcom3e` has digit 3, so replace the character at position 3 i.e., character 'l' with 'M' therefore it
becomes `weMcome`, applying the same for remaining words the output is `weMcome Mo cMmputer Morld`

## input
string with one or multiple words.

## output
string
